## What this repo is

One Colab notebook, `notebooks/cbis_ddsm_whole_image_classifier.ipynb`, that trains a single-view whole-mammogram
benign-vs-malignant classifier on CBIS-DDSM on an A100. Claude Code writes and edits the notebook locally; the user runs
it on Colab and commits the executed notebook / `results/` back. Claude Code does not run training locally; when the
user asks, it may drive a Colab run in the browser pane (the user signs in, picks the runtime and approves Drive access).

## Rules (PRD §12)

- **Never invent, estimate or hand-edit a metric.** Report only what is in notebook outputs or `results/metrics.json`.
  README numbers are generated by a notebook cell.
- **Never set `FINAL_EVAL = True` or load test images without explicit approval in chat.** Test pixels and test DICOM
  headers are not read anywhere before the final-evaluation milestone.
- **Check every dataset assumption with an assert** (columns, counts, file matches). On a mismatch, stop and report it;
  never silently patch. A known, narrowly-matched data defect may be accepted only if it is printed, explained in a
  comment, and shown in the counts table (see the IDC PatientID defect in milestone 4.3).
- **One change per experiment**, logged with its hypothesis in `experiments.csv`. Keep the notebook runnable top to bottom.
- **Stop at review gates** 1 (counts), 2 (baseline) and 3 (before the test run) and wait for approval. Gates are
  `GATE*_APPROVED` flags in the Config cell; only flip one after the user approves in chat.
- **No secrets** in code or outputs. Kaggle/W&B/HF keys come from Colab Secrets (`google.colab.userdata`).
- If 0.90 looks unreachable, say so with evidence. No leakage-prone shortcuts (random image-level splits, tuning on test).

## Notebook conventions

- Helper code lives in the notebook (no local modules) so it runs straight from GitHub in Colab.
- Each PRD §10 milestone = one markdown header + code cells. No cell depends on a later cell.
- Expensive stages are behind `RUN_*` flags and skip when cached outputs exist; long cells print progress.
- Persistent state goes to Drive under `cfg.drive_root`; DICOM / PNG working copies live on the Colab local disk.
- Keep saved outputs small (no huge logs or full-size images).
- Outside Colab, `CBIS_DRIVE_ROOT` / `CBIS_LOCAL_ROOT` redirect paths; with `cfg.download_dicom = False` milestones 0–5
  run as a metadata-only check on any machine.
